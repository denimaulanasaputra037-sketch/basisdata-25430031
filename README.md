## Deskripsi Organisasi
Proyek ini merupakan sistem informasi untuk sebuah perpustakaan fiktif.
Sistem digunakan untuk membantu pengelolaan data buku, anggota, serta
proses peminjaman dan pengembalian buku secara terstruktur.

Perpustakaan fiktif ini melayani anggota yang ingin mencari, meminjam,
dan mengembalikan buku. Sistem dibuat untuk membantu pengelola
perpustakaan dalam menyimpan dan mengelola data secara terorganisasi.
